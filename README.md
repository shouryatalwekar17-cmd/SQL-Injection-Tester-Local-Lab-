# SQL-Injection-Tester-Local-Lab-
A two-part project: a deliberately vulnerable local web app (Flask + SQLite), and a scanner that tests it for SQL injection — showing both the attack and the defense in one project.
# 📌 Project Overview

This project was developed to understand and demonstrate the practical implementation of cybersecurity concepts using Python.

The primary objective of this project is to gain hands-on experience while solving a real-world cybersecurity problem. It serves as a learning project and is intended for educational purposes only.

This project is a two-part cybersecurity lab built using Flask, SQLite, and Python to demonstrate how web vulnerabilities work and how to fix them. It features a lightweight web application with a login system alongside an automated scanner script that sends common SQL injection payloads to test the app's security. By switching between vulnerable string-formatted SQL queries and secure parameterized queries, the project simulates real-world authentication bypass and error-based attacks while proving that parameterized inputs effectively block unauthorized access.

# 📂 Project Structure

```
SQLi_lab/
│
├── database.db          # SQLite database created automatically by init_db.py
├── init_db.py           # Script to create tables and insert dummy data
├── app.py               # Flask web app with vulnerable & secure login routes
├── scanner.py           # Python script that sends SQLi payloads & detects vulnerabilities
│
└── venv/                # Virtual environment containing installed packages (flask, requests)
    ├── Include/
    ├── Lib/
    ├── Scripts/         # Contains activate.bat / Activate.ps1
    └── pyvenv.cfg
```
